# 블록 브레이커 (모바일 버전)

캐릭터를 골라 패들로 벽돌을 깨는 세로형 모바일 게임입니다.
저장소 루트의 PC 버전에서 출발해 TypeScript와 캔버스로 옮기고, 캐릭터마다 다른 게임 방식을 더했습니다. 앱인토스 SDK로 토스 미니앱에 올립니다.

왼쪽부터 꼬마(스와이프 벽돌깨기), 엘프(궁수), 성녀(버티기)입니다.
안드로이드 APK 와 인터넷 없이 열리는 HTML 파일은 저장소의 [Releases](https://github.com/dyd8115-max/PaddleGame/releases) 에서 받을 수 있습니다.

## 실행하기

Node.js 22 이상이 필요합니다.

```
npm install
npm run dev
```

- PC 브라우저에서 터미널에 나온 주소(예: `http://localhost:5173`)를 엽니다. 오른쪽 아래 **AIT** 버튼으로 휴대폰 화면, 안전 영역, 토스 SDK 가짜 응답을 바꿔 볼 수 있습니다.
- 휴대폰으로 보려면 PC와 휴대폰을 같은 와이파이에 연결하고, 터미널에 나온 `Network:` 주소를 휴대폰 브라우저에서 엽니다.

## 토스에 올릴 파일 만들기

```
npm run build
```

`yonginu2022.ait` (appName 과 같은 이름) 가 만들어집니다. 앱인토스 콘솔에 올리고, QR로 토스 앱에서 테스트합니다.
`apps-in-toss.config.ts` 의 `appName` 은 콘솔에 등록한 이름과 같아야 합니다.

## 다른 형태로 만들기

**오프라인 HTML 한 파일**: 그림과 소리를 모두 넣은 파일 하나. 받아서 크롬으로 열면 인터넷 없이 실행됩니다.

```
npm run build
python tools/make_offline_html.py dist 블록브레이커_오프라인.html
```

**안드로이드 앱(APK)**: `android/` 폴더가 Capacitor 로 만든 안드로이드 프로젝트입니다.

```
npm run build
npx cap sync android     # 웹 빌드를 android/ 로 복사
npx cap open android     # Android Studio 로 열기 → Build > Build APK(s)
```

앱 아이콘과 시작 화면은 `python tools/make_android_res.py store android/app/src/main/res` 로 다시 만듭니다.

## 그림과 소리 다시 만들기

PC 버전의 원본 그림과 소리(저장소 루트의 `assets/`, `resources/`)를 웹용으로 바꿉니다. 파이썬과 `Pillow`, `numpy`, `ffmpeg`가 필요합니다.

```
python tools/build_web_assets.py .. public/assets
```

## 캐릭터마다 다른 게임

캐릭터마다 게임 방식과 기록이 다릅니다. 최고 기록은 캐릭터별로 저장됩니다.

| 캐릭터 | 방식 | 기록 |
|---|---|---|
| KID | 스와이프 벽돌깨기. 자리를 골라 직접 조준해서 쏨. 라운드마다 중간 저장 | 도달한 라운드 |
| ELF | 궁수. 끌어서 움직이고 멈추면 자동 발사, 레벨이 오르면 스킬 고르기 | 도달한 스테이지 |
| SAINT | 패들로 받기. 공이 1.5배 빠르고, 3초마다 벽돌 줄이 위에서 생겨 내려옴 | 버틴 시간 |

## 조작

| 동작 | 휴대폰 | PC 브라우저 |
|---|---|---|
| 캐릭터 고르기 | 카드 누르기 | 카드 클릭, 방향키, 1 2 3 |
| 시작 | 시작하기 | Space |
| 쏠 자리 옮기기 (KID) | 흰 바닥선 아래를 좌우로 밀기 | 바닥선 아래를 누른 채 끌기 |
| 조준하고 쏘기 (KID) | 바닥선 위를 누른 채 아래로 당기고 놓기 | 누른 채 당기고 놓기 |
| 이동 (ELF) | 화면 어디든 누른 채 끌기 (조이스틱) | 누른 채 끌기 |
| 스킬 고르기 (ELF) | 카드 누르기 | 카드 클릭 |
| 패들 이동 (SAINT) | 화면 아래쪽을 좌우로 밀기 | 마우스 |
| 일시정지 | 왼쪽 위 Ⅱ, 안드로이드 뒤로가기 | P, Esc |
| 소리 켜기·끄기 | 스피커 버튼 | M |

## 규칙: KID (스와이프 벽돌깨기)

- 흰 바닥선 아래를 밀면 꼬마가 걸어가 쏠 자리를 고릅니다. 바닥선 위를 누른 채 아래로 당기면 반대쪽으로 조준선이 보이고, 두 번째로 부딪치는 곳까지 꺾여 보입니다. 손을 떼면 가진 공을 차례로 쏩니다.
- 벽돌의 숫자만큼 맞혀야 깨집니다. 초록 +1(라운드마다 하나)을 지나가면 다음 차례부터 공이 하나 늘어납니다.
- 공이 모두 바닥에 돌아오면 새 벽돌 줄이 1줄(50%), 2줄(30%), 3줄(20%) 생기면서 한꺼번에 내려옵니다. 줄마다 벽돌 수는 1~6개 무작위, 숫자는 라운드 수(가끔 2배).
- 벽돌이 바닥선에 닿으면 끝. 공 빠르기는 라운드와 상관없이 같고, 한 차례가 8초를 넘기면 2배로 빨라집니다.
- 라운드마다 중간 저장됩니다. 그만두거나 앱을 닫아도 메뉴에서 '이어하기'로 계속하고, '처음부터'로 새로 시작합니다.

## 규칙: ELF (궁수)

- 화면 어디든 누른 채 끌면 엘프가 그 방향으로 움직입니다. 화면 아래쪽 절반(빨간 점선 아래) 안에서 자유롭게 다닙니다.
- 멈춰 있으면 가장 가까운 적에게 화살을 자동으로 쏩니다. 움직이는 동안은 쏘지 않습니다.
- 적은 숫자(체력)가 있는 벽돌입니다. 천천히 내려오고, 보라색 벽돌은 엘프에게 탄을 쏩니다(10스테이지부터 세 갈래). 5스테이지마다 큰 벽돌 보스가 나와 좌우로 움직이며 쏘고, 가끔 다섯 갈래로 탄을 퍼뜨립니다.
- 적을 모두 잡으면 다음 스테이지, 체력이 1 회복됩니다. 탄에 맞거나 벽돌이 빨간 점선에 닿으면 체력 -1. 체력 5개가 모두 없어지면 끝.
- 벽돌을 깨면 경험치가 차고(위쪽 초록 막대), 레벨이 오르면 스킬 3개 중 하나를 고릅니다.

  | 스킬 | 효과 | 최대 |
  |---|---|---|
  | 멀티샷 | 한 번 더 연속으로 쏨 | 2 |
  | 앞쪽 화살 +1 | 나란히 한 발 더 | 2 |
  | 사선 화살 | 양옆 비스듬히 두 발 더 | 1 |
  | 튕기는 화살 | 맞히면 다른 적에게 튕김 | 2 |
  | 벽 반사 | 벽에 맞으면 튕김 | 2 |
  | 관통 | 적을 뚫고 지나감 | 2 |
  | 공격 속도 +25% | 더 자주 쏨 | 3 |
  | 공격력 +1 | 한 발이 더 아픔 | 4 |
  | 체력 회복 | 최대 체력 +1, 모두 채움 | - |

## 규칙: SAINT (버티기)

- 위쪽과 좌우 벽은 닫혀 있고 아래만 열려 있습니다. 공은 들어온 각도 그대로 반사됩니다. 공을 모두 놓치면 끝입니다.
- 공이 1.5배 빠릅니다. 3초마다 맨 위에 벽돌 줄(1~8개 무작위)이 생기고 전체가 한 줄 내려옵니다. 빨간 점선에 벽돌이 닿으면 끝. 30초부터 악마가 패들 위에 올라타 공을 가립니다.
- 벽돌을 깨면 30% 확률로 아이템이 떨어지고, 노란 벽돌은 항상 떨어집니다. 패들로 받으면 효과가 납니다.

  | 아이템 | 효과 |
  |---|---|
  | 공×2 | 지금 있는 공이 2배 |
  | 공×3 | 지금 있는 공이 3배 |
  | 공÷2 | 공이 절반 (최소 1개) |
  | 패들×1.5 | 패들 1.5배 |
  | 패들÷3 | 패들 3분의 1 |

- 늘어난 공은 색이 무작위입니다. 하양(기본 빠르기) 40%, 빨강(1.5배) 30%, 초록(0.5배) 30%. 공은 최대 30개까지.
- 공이 한동안 벽돌을 못 깨고 같은 길만 오가면, 패들이나 벽에 맞을 때 방향이 조금 바뀝니다.

## 폴더 구성

```
src/
  game/        게임 규칙 (화면, 입력, 소리와 무관)
    geometry.ts  벡터와 사각형 충돌
    objects.ts   공, 패들, 벽돌, 캐릭터, 악마
    game.ts      게임 진행, 성녀 모드 (버티기)
    swipe.ts     꼬마 모드 (스와이프 벽돌깨기)
    archer.ts    엘프 모드 (궁수)
    collide.ts   공 충돌, 같은 길만 도는 공 방향 바꾸기
  main.ts      시작점: 화면 크기, 입력, 게임 루프, 저장
  layout.ts    세로 휴대폰 화면 배치
  render.ts    캔버스 그리기
  audio.ts     배경음악과 효과음
  platform.ts  앱인토스 SDK 연결 (저장, 안전 영역, 뒤로가기, 리더보드)
  ui.ts        버튼 위치
public/assets/ 그림과 소리
store/         앱인토스 콘솔에 올리는 로고, 썸네일, 스크린샷
tools/
  build_web_assets.py  PC 버전 원본 그림·소리를 웹용으로 변환
  store_shots.py       콘솔용 세로 스크린샷 찍기
  store_art.py         콘솔용 로고, 썸네일, 공유 이미지 만들기
  make_web_preview.py  빌드 결과를 미리보기 페이지 하나로 묶기
  make_offline_html.py 인터넷 없이 열리는 HTML 한 파일 만들기
  make_android_res.py  안드로이드 앱 아이콘과 시작 화면 만들기
android/       안드로이드 앱 프로젝트 (Capacitor)
apps-in-toss.config.ts 앱인토스 설정
capacitor.config.ts    안드로이드 앱 설정
```
